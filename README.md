## 📖 Project Description

**Calculator Master** is a menu-driven calculator application built to demonstrate the practical use of **Git**, **GitHub branching**, and **collaborative version control workflows** in a software development setting.

The project simulates a real development team scenario: each arithmetic operation (addition, subtraction, multiplication, division) was developed on its own isolated feature branch, committed incrementally with descriptive messages, submitted through a Pull Request, reviewed, and merged into `main` — reflecting industry-standard source code management practices.

---

## 🌿 Branch Structure


Each feature branch was merged into `main` via a reviewed and approved Pull Request, with a minimum of two meaningful commits per branch.

---

## ✨ Program Features

- 🖥️ Menu-driven interface for selecting operations
- 🔁 Continuous execution until the user selects **Exit**
- 🛡️ User input validation — rejects non-numeric entries gracefully
- ➗ Division-by-zero handling with a clear error message
- 🧩 Modular, function-based design — one function per operation
- ✅ Proper error handling for invalid menu selections

---

## ⚙️ How to Run

```bash
python3 calculator.py
```

Follow the on-screen menu, choose an operation (1–5), and enter two numbers when prompted.
